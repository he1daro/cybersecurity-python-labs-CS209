# Лабораторна робота №4: Інтеграція із зовнішніми Web API та автоматизоване тестування

Консольна утиліта для отримання записів про вразливості з NVD CVE API 2.0 (або локального JSON-файлу), валідації структури відповіді та формування звіту за правилом **варіанта 14**.

## Правило варіанта 14

* **Метрика CVSS v3.1:** `availabilityImpact` (вплив на доступність)
* **Очікуване значення (`expected`):** `"LOW"`
* **Поріг базової оцінки (`threshold`):** `6.0`
* **Умова переходу у стан `review`:** `score >= 6.0` та `cvssData["availabilityImpact"] == "LOW"`

## Встановлення залежностей

Виконуйте команди з кореня репозиторію в активованому віртуальному середовищі:

```bash
python -m pip install -r requirements.txt
```

## Запуск проекту
```bash
python -m labs.lab04.main --cve CVE-2099-10001 --input labs/lab04/data/nvd_sample.json
```
